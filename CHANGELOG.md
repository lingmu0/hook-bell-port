# 1.0.1 — Minecraft 26.1.2 / NeoForge

- Ported the standalone Hook Bell to Minecraft 26.1.2 and NeoForge 26.1.2.116.
- Updated block registration, interaction, entity tags, and bell rendering to the new APIs.
- Updated the item model and recipe formats. Craft with eight Ender Pearls surrounding one Bell.
- Preserved the block event fix that allows the bell to summon raiders when loaded without Goety.
- Preserved the 128 block call range, obstruction checks, custom name exclusion, and configurable blacklist.
- Requires Java 25. No Goety dependency.
